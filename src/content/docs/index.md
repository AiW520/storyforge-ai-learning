## 学完能做什么

解释项目启动过程，追踪一条核心流程，定位对应函数，并在副本里完成一项有验证方法的小改动。

## 选择阅读路线

**快速入门：** 项目全貌 → 快速上手 → 真实流程 → 实践练习。

**深入阅读：** 架构与数据 → 流程 → 源码精读 → 安全与维护 → 证据核对。
